偏好设置

设置

外观、加载速度，以及本地保留了什么。

外观

主题“跟随系统”会随 Windows 的浅色/深色设置切换。
配色方案整套配色，包括背景与面板色调。“高对比度”和“赛博朋克”只有深色版本，选中后会自动切到深色。
主题色在配色方案之上单独换掉高亮色。留空即用方案自带的颜色。
减弱动效如果觉得动画拖沓，可以缩短所有过渡。

加载与播放

文件按 512KB 分片下载。同时在传的分片越多，等待 Telegram 往返的时间就越少，代价是占用更多带宽。

并行分片数 8播放时同时发出的请求数。代理较慢时可以调高。
预加载分片 16按下播放前先取好的分片，让开头直接从本地读取。
预读文件尾部M4A 和 MP4 的索引表在文件末尾。提前取回可以避免开播前的那一次卡顿。
保持连接活跃音频文件可能存放在与账号不同的 Telegram 服务器上，那条连接闲置 30 秒后会被断开，下次播放要重新建立。开启后会在播放期间用最小请求维持它。

窗口与托盘

开启后，点右上角的关闭按钮只是把窗口收起来，音乐继续播，Telegram 连接也不断开。真正退出请用托盘菜单里的“退出 TGPlayer”。

关闭时最小化到托盘托盘图标可以播放/暂停、切上下一首；单击图标恢复窗口。关掉这个开关则关闭窗口就直接退出。

存储

每个到达的分片都会写入磁盘，所以重听或往回拖动进度完全不消耗流量。

登录凭据和音乐库索引已加密，绑定当前 Windows 账户，换账户或换机器都解不开。音频缓存和封面是普通文件，同一台电脑的其他 Windows 账户可以读取——介意的话用下面的按钮清空。

--音频缓存0 首
--封面0 张
